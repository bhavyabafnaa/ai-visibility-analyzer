# Screenshot capture checklist

The README intentionally contains screenshot placeholders for the 0.1.0 release candidate.
Capture real images only after the final Compose validation.

Target files:

- `project-setup.png` — 1440×900, pre-filled Acme Cloud setup.
- `evidence-overview.png` — 1440×1000, completed deterministic run and metric cards.
- `recommendations.png` — 1440×1000, top ranked recommendation with evidence expanded.

Use only MockProvider data. Confirm that no local paths, provider keys, terminal windows, browser
extensions, account identifiers, or non-sample URLs are visible. Replace the README blockquotes
with image links after the files are reviewed.
