# GeoLens 0.1.0

Release date: 2026-07-31

## Overview

GeoLens 0.1.0 is a local release-candidate AI visibility and citation
intelligence platform.

It combines:

- a FastAPI API;
- a Next.js evidence dashboard;
- PostgreSQL persistence;
- Redis-backed Celery workers;
- bounded website crawling;
- provider-neutral AI-response normalization;
- deterministic visibility scoring;
- evidence-linked GEO recommendations.

## Highlights

- FastAPI project, crawl, provider-analysis, citation, entity, score, and claim
  APIs.
- Next.js dashboard with deterministic sample onboarding and MockProvider
  analysis.
- PostgreSQL schema managed through Alembic.
- Idempotent Acme Cloud demonstration seed.
- Redis/Celery queues for both website crawling and provider analyses.
- Secure, DNS-pinned, exact-host website crawler.
- Provider-neutral adapters for MockProvider, OpenAI, Gemini, and Perplexity.
- Deterministic visibility, citation, share-of-voice, entity, retrieval, and
  claim-risk formulas.
- Multi-stage frontend container and non-root backend container.
- Five-service Docker Compose topology with health and readiness gates.
- GitHub Actions CI for linting, formatting, type checking, unit tests,
  PostgreSQL integration tests, frontend tests, production builds, Compose
  validation, and container builds.
- Recruiter-facing README with reproducible MockProvider metrics and real
  dashboard workflow screenshots.

## Dashboard workflow

The dashboard supports:

- project creation and switching;
- target brand, alias, and competitor configuration;
- provider and prompt selection;
- website crawl submission;
- persisted crawl-state recovery;
- crawl-status polling;
- asynchronous analysis submission;
- analysis-status polling;
- citation and entity evidence;
- deterministic metrics;
- claim review;
- ranked GEO recommendations.

A succeeded crawl belonging to the active project can be attached to the next
analysis as optional website evidence.

The seeded `.example` project remains non-routable and is used only for the
deterministic, no-network MockProvider demonstration.

## Asynchronous analysis execution

`POST /analyses` now:

1. validates the project and optional crawl;
2. resolves exact provider and model configurations;
3. persists a pending analysis run;
4. stores prompts and provider configuration;
5. enqueues the analysis through Celery;
6. returns HTTP 202.

The dashboard polls:

```text
GET /analyses/{analysis_id}
```

until the run reaches a terminal state.

Supported analysis states are:

```text
pending
running
succeeded
completed_with_errors
failed
```

Provider and model identifiers are pinned when the run is submitted. The worker
rejects model-configuration drift instead of silently executing a different
model.

## Website crawler

The crawler:

- validates HTTP and HTTPS targets;
- blocks private, local, link-local, metadata, multicast, and reserved
  destinations;
- resolves and pins public addresses;
- revalidates redirects;
- stays on the configured hostname;
- observes robots rules;
- discovers sitemap URLs;
- applies bounded page, depth, response-size, redirect, timeout, and concurrency
  limits;
- stores extracted page content and crawl errors.

The dashboard can queue a crawl, poll its state, display terminal page and error
counts, and attach a succeeded crawl to the next analysis.

## Provider execution

GeoLens 0.1.0 includes adapters for:

- MockProvider;
- OpenAI;
- Gemini;
- Perplexity.

Provider-specific response structures are normalized into a common contract
containing:

- response text;
- citations;
- raw response JSON;
- token usage;
- latency;
- model identifier;
- status;
- structured error information.

Live providers require both an API credential and an explicit account-enabled
model identifier.

Missing credentials disable only the affected provider. GeoLens never silently
falls back to another provider.

## Analysis and scoring

GeoLens implements deterministic calculations for:

- visibility rate;
- target-domain citation coverage;
- citation share;
- rank-weighted share of AI voice;
- entity coverage.

Claim-support analysis separates:

1. deterministic claim segmentation;
2. deterministic evidence retrieval;
3. explicit model-assisted classification.

Model-assisted claim-support risk is disclosed as a prioritization estimate, not
objective truth.

## Reliability and security hardening

- Moved provider analyses from synchronous API execution into Celery workers.
- Persisted exact queued provider and model configurations.
- Added analysis lifecycle polling.
- Added Redis-backed CI coverage for queued analysis execution.
- Moved Celery enqueue operations off the async API event loop.
- Ended database transactions before provider and classifier network calls.
- Corrected multi-part provider citation offsets.
- Rejected unsafe provider citation links.
- Independently sanitized frontend evidence links.
- Removed unused provider credentials from crawl-worker configuration.
- Preserved exact response prompt and provider context for persisted claims.
- Prevented unconfigured claims from appearing as model-classified risk.
- Added bounded prompt, provider-name, alias, and citation-URL validation.
- Added project-scoped crawl recovery and polling cleanup.
- Prevented stale or cross-project crawl identifiers from being attached to
  analyses.

## Schema and migrations

GeoLens 0.1.0 applies Alembic migrations through revision:

```text
0004
```

Revision `0004` adds queued-analysis configuration to `analysis_runs`,
including:

- `celery_task_id`;
- `provider_configurations`;
- `prompts`;
- `claim_classifier_configuration`.

The API container runs:

```text
alembic upgrade head
```

before Uvicorn starts.

For deployments with multiple API replicas, migrations should run as one
serialized external job rather than independently in every replica.

## Known limitations

GeoLens 0.1.0 does not include:

- authentication;
- authorization;
- tenant isolation;
- rate limiting;
- TLS termination;
- production observability;
- audit logs;
- historical analysis comparison;
- historical crawl selection;
- scheduled execution;
- analysis cancellation;
- a bundled JavaScript renderer.

Provider APIs may change independently of GeoLens, and live-provider tests remain
opt-in.

See [../limitations.md](../limitations.md) and
[../security.md](../security.md) before deploying or enabling live providers.
